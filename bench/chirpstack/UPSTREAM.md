## Security notes

- The PostgreSQL password and the anonymous MQTT access are the upstream
  defaults. They are acceptable here because PostgreSQL has no published
  port and MQTT is published on 127.0.0.1 only.
- The Semtech UDP protocol has no authentication. UDP 1700 is published on
  the bench address 10.10.2.2 only, which is not reachable from other hosts.
- The API secret is generated by `bench/bench.sh up` and stored in `.env`,
  which is not in the repository.
